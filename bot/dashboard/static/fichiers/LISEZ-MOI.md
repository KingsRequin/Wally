# Fichiers hébergés

Dépose un fichier ici, il est en ligne **tout de suite** :

    https://heywally.fr/static/fichiers/<nom-du-fichier>

Aucun redémarrage, aucun rebuild : le dossier est monté en direct dans le
conteneur.

## Bon à savoir

- **Rien n'est versionné.** Le `.gitignore` de ce dossier tient tes fichiers
  hors du dépôt, qui est public. Ne le supprime pas.
- **Nomme sans espaces ni accents** : `ma-banniere.png` plutôt que
  `Ma Bannière.png`. Sinon l'URL se remplit de `%20` et de codes à rallonge.
- **L'URL est publique** et devinable par qui connaît le nom du fichier. Rien de
  privé ici.
- Pour Discord, colle l'URL telle quelle : l'aperçu se fait tout seul sur les
  formats d'image courants, `.webp` compris.
